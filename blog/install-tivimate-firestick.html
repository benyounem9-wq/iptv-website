How to Install TiviMate on Firestick (2025 Complete Guide)

6 min read January 2025 BestIPTVToday Team

Amazon Firestick does not have TiviMate on its app store, but you can easily sideload it using the free Downloader app. This guide covers the complete process — enabling developer options, installing the APK, and setting up your IPTV service — in under 10 minutes.

What You Need

  • Amazon Firestick (any generation, including 4K and 4K Max)
  • Active IPTV subscription (M3U URL or Xtream Codes credentials)
  • Wi-Fi connection (ethernet adapter recommended for 4K)
  • A few minutes of your time

Note: Enabling "Apps from Unknown Sources" only allows you to install apps outside the Amazon Store — it does not affect your device's warranty or security when used for legitimate apps like TiviMate.

Step 1 — Enable Apps from Unknown Sources

  1. Press the Home button on your Firestick remote
  2. Navigate to Settings (gear icon, top right)
  3. Select My Fire TV
  4. Choose Developer Options
  5. Toggle Apps from Unknown Sources to ON
  6. Also enable ADB Debugging (optional but useful)

Step 2 — Install the Downloader App

  1. Go back to the Home screen
  2. Open the Search function (magnifying glass icon)
  3. Type "Downloader" and select the orange Downloader app by AFTVnews
  4. Click Download and wait for installation
  5. Open Downloader and grant it storage permission if prompted

Step 3 — Download and Install TiviMate APK

  1. Open the Downloader app
  2. In the URL bar, type the TiviMate APK address from the official TiviMate website
  3. Tap Go — the download will begin automatically
  4. Once downloaded, tap Install
  5. After installation tap Open to launch TiviMate immediately
  6. You can delete the APK file from Downloader to free space

Tip: On newer Firestick firmware, you may see a warning screen. Select "Install Anyway" — this is normal for sideloaded apps.

Step 4 — Connect Your IPTV Service

  1. Open TiviMate on your Firestick
  2. Tap Add Playlist
  3. Choose Xtream Codes API (recommended) or M3U Playlist
  4. Enter your BestIPTVToday credentials — Server URL, Username, Password
  5. Tap Next and let TiviMate load your channel list
  6. Add your EPG URL for the full TV guide

Firestick Performance Tips

  • Clear cache regularly: Settings → Applications → TiviMate → Clear Cache every few weeks
  • Use ethernet: A USB-to-ethernet adapter removes Wi-Fi interference for buffer-free 4K
  • Close background apps: Hold the Home button → App switcher → close unused apps before streaming
  • Increase buffer: TiviMate Settings → Playback → set buffer to 10 seconds minimum
