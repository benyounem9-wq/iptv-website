Kodi IPTV Setup: PVR IPTV Simple Client Complete Guide (2025)

7 min read July 2025 BestIPTVToday Team

Kodi is a powerful open-source media centre that can be turned into a full IPTV system using the PVR IPTV Simple Client addon. Kodi runs on Windows, Mac, Linux, Android, Raspberry Pi, and more — making it one of the most versatile IPTV platforms available.

Step 1 — Enable PVR IPTV Simple Client

  1. Open Kodi (download from kodi.tv if not installed)
  2. Go to Settings (gear icon) → Add-ons
  3. Select My add-ons → PVR clients
  4. Find PVR IPTV Simple Client and click Enable
  5. If not listed, go to Add-ons → Install from repository → Kodi Add-on repository → PVR clients → PVR IPTV Simple Client → Install

Step 2 — Configure the Addon

  1. After enabling, click Configure on the PVR IPTV Simple Client
  2. In the General tab, set M3U Playlist URL → select Remote path (internet address)
  3. Paste your M3U URL in the M3U URL field
  4. Switch to the EPG Settings tab
  5. Set XMLTV URL to Remote path and enter your EPG URL
  6. Click OK and restart Kodi when prompted

Step 3 — Access Your Live Channels

  1. From the Kodi home screen, select TV
  2. Your channel list loads — browse by group or use search
  3. Press C (keyboard) or the Menu button (remote) on a channel for options
  4. Access the EPG Guide from the TV section → Guide

Kodi tip: If you see "Channels not available", allow 2–3 minutes for Kodi to fully download and index your M3U playlist and EPG data. Large playlists (25,000+ channels) may take a few minutes on first load.
