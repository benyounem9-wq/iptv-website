SS IPTV Tutorial: Complete Samsung Smart TV Setup (2025)

6 min read May 2025 BestIPTVToday Team

SS IPTV is a free IPTV app available on Samsung Smart TVs (Tizen OS) and LG Smart TVs (webOS). It supports M3U playlists, Xtream Codes API, and custom EPG — all without a subscription fee. This tutorial covers the complete setup from installation to watching live channels.

Step 1 — Install SS IPTV

Samsung Tizen TV

  1. Press Home on your Samsung remote
  2. Open Apps → tap the search icon
  3. Type "SS IPTV" and press Enter
  4. Select SS IPTV and click Install
  5. Open the app — you will see the main player interface

LG webOS TV

  1. Open LG Content Store (TV app store)
  2. Search "SS IPTV" and install

Step 2 — Add M3U Playlist

  1. Open SS IPTV on your TV
  2. Press the Settings button (gear icon) or navigate to Menu → Playlist
  3. Select Add External Playlist
  4. Choose URL as the source type
  5. Use the on-screen keyboard to enter a name for your playlist
  6. Enter your M3U URL — use a smartphone with a Bluetooth keyboard or remote QR scan if available on your TV
  7. Tap Save → the playlist loads automatically

Tip: Entering long URLs with a TV remote is slow. Use the SS IPTV companion app on your phone to send playlists to the TV via QR code or the web interface — much faster.

Add Xtream Codes (Alternative)

  1. In SS IPTV Settings → Add Xtream Codes Playlist
  2. Enter your Server URL, Username, and Password
  3. SS IPTV will import all live channels, VOD, and series

Step 3 — Set Up EPG

  1. Go to SS IPTV Settings → EPG Sources
  2. Select Add EPG Source → Remote EPG (URL)
  3. Enter your EPG XMLTV URL (available from BestIPTVToday account details)
  4. Save and wait for EPG to populate (5–10 minutes for full load)

Navigating SS IPTV

  • Channel list: Left panel — browse by group or search by name
  • EPG overlay: Press OK while watching to see current/next programme info
  • Full EPG guide: Press the EPG button in the top menu
  • VOD section: Access via the Movies tab in the top navigation
  • Favourite channels: Long-press a channel to add to favourites
